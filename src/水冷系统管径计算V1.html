计算步骤

1. 计算供回水温差
Δt = T供 - T回 = 0 °C
2. 获取介质物性参数
ρ = 0 kg/m³, c = 0 kJ/(kg·°C)
3. 计算所需体积流量
G = Q / (ρ × c × Δt ×) 3600 × 安全系数 = 0 m³/h
4. 计算管道内径
d = √(4G / (3600 × π × v)) × 1000 = 0 mm
5. 选择标准管道规格
